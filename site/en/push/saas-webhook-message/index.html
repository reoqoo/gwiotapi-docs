Webhook Callback Handling

Section titled “Webhook Callback Handling”

The webhook receiver should:

Verify Signature: Ensure message authenticity through X-IotVideo-Signature

Idempotent Processing: Avoid duplicate processing via eventId

Asynchronous Processing: Use asynchronous approach for time-consuming operations

Error Retry: Failed messages will be retried

Status Confirmation: Return confirmation response
