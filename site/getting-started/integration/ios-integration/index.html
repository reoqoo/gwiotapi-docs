iOS 集成

插件链接预编译的静态 framework GWIoTKit（发布在 CocoaPods trunk）。最低支持 iOS 15。有几项构建设置 无法由插件 podspec 提供，必须写在宿主 App 的 Podfile 里。

1. Podfile 要求

Section titled “1. Podfile 要求”

同时在 Xcode 里把宿主 App 的 iOS Deployment Target 设为 15.0 及以上 （Runner target → Build Settings → iOS Deployment Target）。CocoaPods 无法通过 podspec 抬高宿主 App 的部署目标。

2. 插件已经处理的部分

Section titled “2. 插件已经处理的部分”

ios/gwiot_flutter_plugin.podspec 已为自身 pod target 设置下列内容，你无需重复：

配置 取值 作用范围
DEFINES_MODULE YES 插件 pod target
BUILD_LIBRARY_FOR_DISTRIBUTION YES 插件 pod target
EXCLUDED_ARCHS[sdk=iphonesimulator*] arm64 i386 仅插件 pod target

宿主 App target 由另外两方覆盖，因此插件无需再经 user_target_xcconfig 透传该设置：

  • GWIoTKit 同时以 pod_target_xcconfig 与 user_target_xcconfig 携带 EXCLUDED_ARCHS[sdk=iphonesimulator*] = arm64，因此会作用到宿主 target （Pods-Runner.*.xcconfig）。
  • Flutter 工具链会把 EXCLUDED_ARCHS[sdk=iphonesimulator*]=i386 arm64 写入 ios/Flutter/Generated.xcconfig，作用于宿主 App。

IPHONEOS_DEPLOYMENT_TARGET 不在、也无法由任何 podspec 覆盖——CocoaPods 只用它设置 pod 自身的 target。必须写进你的 Podfile（如上）以及 Xcode target。

4. 模拟器架构

Section titled “4. 模拟器架构”

SDK 的静态 framework 没有 arm64 模拟器 slice。Apple Silicon 上有两种选择：

  1. 用 Rosetta（x86_64）跑模拟器，上文 EXCLUDED_ARCHS 设置正是为此。
  2. 使用真机。

若不做排除，模拟器构建会在链接阶段因缺少 arm64 slice 而失败。

5. 运行期要求

Section titled “5. 运行期要求”

  • 原生页面需要可用的导航栈。 SDK 展示的页面通过当前导航栈 push，因此宿主必须满足两项：

    1. key window 上有根视图控制器（Flutter 容器已挂载），否则插件返回错误码 25100；
    2. 根视图控制器的链路上存在 UINavigationController，否则插件返回错误码 25101。

    两项都不满足时页面不会出现，SDK 也不会回调错误；插件把它们变成可读的错误码，避免宿主把 「页面没出现」当成 SDK 的问题。

    Flutter 模板生成的根控制器是 FlutterViewController，需要在 AppDelegate 里包一层 导航控制器：

    若宿主使用 SceneDelegate（Info.plist 里存在 UIApplicationSceneManifest）， didFinishLaunchingWithOptions 阶段 window 可能仍为 nil，请在 scene(_:willConnectTo:) 里做同样的包装。

  • 推送的注册由宿主 App 负责，展示与跳转仍归 SDK。 插件不申请权限、不注册 token，只把你交给它的 token 传给 SDK。技威云在 iOS 上只认 APNs token：接 FCM 的宿主也要把 APNs token 上报上去， FCM token 云端用不上。收到推送或点击通知后，把 userInfo 交给 receivePushNotification / clickPushNotification，解析、展示与跳转由 SDK 负责。

  • 不支持 macOS。 插件只声明 android 与 ios 两个平台；GWIoT 的功能集依赖 GWIoTKit， 而它不在 macOS 上链接。

6. 常见报错排查

Section titled “6. 常见报错排查”
现象 原因
Unable to find a specification for 'GWIoTKit' Podfile 只声明了 Gwell 私有 spec 源，需要加上 CocoaPods trunk。
模拟器链接报缺少 arm64 slice 来自 GWIoTKit 与 Generated.xcconfig 的 EXCLUDED_ARCHS 被删除或被覆盖。Apple Silicon 请用 Rosetta 或真机。
The platform of the target 'Runner' (iOS 13.0) is not compatible with 'gwiot_flutter_plugin' which has a minimum requirement of iOS 15.0 宿主部署目标低于 15.0。
链接错误提到 Swift 并发或 swiftCompatibility* 符号 宿主 post_install 缺少 BUILD_LIBRARY_FOR_DISTRIBUTION = YES。
原生页面调用返回 25100 没有可用的 keyWindow.rootViewController；调用发生在 UI 就绪之前。
原生页面调用返回 25101 根控制器没嵌进 UINavigationController（Flutter 模板默认如此），SDK 页面无处可 push。按上文第 5 节包装根控制器。
