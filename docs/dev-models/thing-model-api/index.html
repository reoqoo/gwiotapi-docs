物模型 branch 说明

Section titled “物模型 branch 说明”
branch 类型 示例 描述
ProConst.devFuncCfg int32 8192 设备功能支持项，设置相关设置项前需检查是否支持。
bit12: 设备支持端侧AI火焰检测, 1:支持
bit13: 设备支持端侧AI车辆检测, 1:支持
bit14: 设备支持端侧AI宠物检测, 1:支持
bit15: 设备支持端侧烟雾报警检测，1:支持
ProWritable.guardParm.setVal.aiDetectEn int32 8 AI检测设置项: 1打开，0：关闭，不同bit表示不同项，设置某一项开关前需先查询后再设置，避免影响其他bit位。
bit0/bit1/bit2暂不使用
bit3:车辆检测 
bit4:火焰检测 
bit5:烟雾报警开关(设备需复位绑定才默认开启) 
bit6:宠物检测开关
…..
ProWritable.guardParm.setVal.plan Json {
    “start”: {
        “hour”: 0,
        “min”: 0
    },
    “end”: {
        “hour”: 0,
        “min”: 0
    },
    “weekdayEn”: 127
}		 守护计划设置
start：开始时间
end：结束时间
weekdayEn：按位表示，
BIT 0~6 表示星期天~星期六，bit0 表示星期天，bit1 表示星期一，以此类推。若设置的时间段跨天，即结束时间 < 开始时间，以开始时间当天的使能标志位作为判断。
例如，设置的智能守护时间为 18：00~8：00，设置工作日使能为 周一~周五，则周五晚上 18：00~周六上午8：00 需要开启警戒计划，周日18：00 ~周一8：00 不开启。定时计划的触发，是时刻点的触发
