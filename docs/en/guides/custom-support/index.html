Custom technical support

Overview

Section titled “Overview”

The SDK has a built-in help & feedback page. When the app already has its own support system, ticketing system or feedback form, replace it through two seams:

Seam What it controls
IHostSupportEntryService Whether the help & feedback entry in the built-in page shows
IHostSupportService Which page opens after the user taps in

You can use only one of the two seams: to hide the entry only, implement the first one; to swap the page only, implement the second one.

How it works

Section titled “How it works”

Whether the entry shows (IHostSupportEntryService):

  1. When the SDK renders the built-in page, it checks whether IHostSupportEntryService is registered.
  2. If it is registered, it calls isHiddenSupportEntry() and the app decides whether to show or hide.
  3. If it is not registered, the SDK’s default configuration applies (shown).

After the user taps in (IHostSupportService):

  1. When the SDK needs to open the technical support page, it checks whether IHostSupportService is registered.
  2. If it is registered, it calls openSupportCenterPage(device, type), and the app decides which page opens.
  3. If it is not registered, the SDK’s built-in help page opens.
