gwiot_flutter_plugin overview

中文文档

A Flutter wrapper for Gwell’s GWIoT KMP SDK. It bundles the Android AAR (com.gwell:gwiotapi) and the iOS GWIoTKit framework behind a single top-level GWIoT facade, so the same Dart calls work on both platforms without touching Kotlin or Swift directly.

Requirements

Section titled “Requirements”
Item Requirement Notes
Flutter Whatever pubspec.yaml pins in environment.flutter An older SDK fails at flutter pub get; only the most recent 3 Flutter stable releases are supported.
Dart Constrained together with Flutter (environment.sdk) The code uses sealed class, switch expressions, and other Dart 3 features.
Android minSdk / compileSdk / Java versions live in the plugin’s android/build.gradle Depends on com.gwell:gwiotapi from Gwell’s private Nexus (exact version in that same file). Host apps need GWIOT_MAVEN_USERNAME / GWIOT_MAVEN_PASSWORD.
iOS Minimum OS version lives in the plugin’s ios/gwiot_flutter_plugin.podspec Depends on GWIoTKit from CocoaPods trunk (constraint in that same podspec). On Apple Silicon, run the simulator under Rosetta (x86_64) or use a device.

Version policy: only the most recent 3 Flutter stable releases are supported. When the host app moves to a newer Flutter, raise both sdk and flutter in pubspec.yaml and re-run flutter analyze, flutter test, and both platform builds.

Install

Section titled “Install”

Git tag (internal apps only — GitLab is intranet-only)

Section titled “Git tag (internal apps only — GitLab is intranet-only)”

Use an exact release tag as ref (the tag equals pubspec.yaml’s version, with no v prefix) — never a branch. Available tags are listed on the GitLab Tags page or by git tag -l.

⚠️ （内部主机已隐去） is reachable only from the intranet, so this form works for internal host apps only; customers and partners should use the private Pub source below (reachable from outside).

Gwell private Pub source

Section titled “Gwell private Pub source”

Add a version: constraint when you need to pin one; available versions are listed by the metadata query in publishing.md. The repository currently allows anonymous reads, so customers and partners need no credentials.

Quick start

Section titled “Quick start”

Register any host services before initializing, then initialize and wait for the SDK to become ready:

Transport, codec, and call-contract problems throw GwiotException; SDK business failures are returned as GwiotResult.failure and must be handled explicitly.

Call await GWIoT.dispose() when tearing down, which releases every native observer and subscription.

Platform setup

Section titled “Platform setup”

Both platforms need extra configuration in the host app — the plugin cannot do it for you:

Platform What the host app must do Guide
Android Declare Gwell’s private Maven repositories and provide credentials; minSdk / compileSdk / Java versions live in the plugin’s android/build.gradle. android-integration.md
iOS In the Podfile: platform :ios, '<minimum the plugin requires>', use_frameworks! :linkage => :static, and a post_install block; CocoaPods trunk must be reachable. ios-integration.md
