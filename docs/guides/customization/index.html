定制概述

在功能与职责边界里，介绍了SDK支持定制的功能，这里列出具体的实现指南。

定制文档

Section titled “定制文档”
要定制什么 读哪一篇 主要接口
用自己的页面替换云服务页或流量页 自定义云服务与流量 IHostCloudService、IHostTrafficService
设备设置项与事件开关的可见性 自定义设备设置 IHostSettingService
让同一账号体系下的其他用户共用设备 设备分享 IHostAccountService
用自己的客服与反馈页替换内置帮助页 自定义技术支持 IHostSupportService、IHostSupportEntryService
更多…. 完整接口列表可查IHostService。

通用实现步骤

Section titled “通用实现步骤”
  1. 从接口选择需要自定义的功能。
  2. 实现对应接口协议，并注册给 SDK。
  3. SDK在触发相关功能时调用相关实现。
