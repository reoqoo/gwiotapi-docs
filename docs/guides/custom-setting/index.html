自定义设备设置

概述

Section titled “概述”

SDK 的设备设置页面（智能守护）默认展示完整的事件侦测时间段和所有支持的事件类型开关。当 App 需要自定义这些设置项的可见性时（例如：根据设备型号、用户权限或业务需求隐藏部分功能），可以通过实现 IHostSettingService 接口来控制。

工作原理

Section titled “工作原理”

当 SDK 内部需要展示设备设置页面的【智能守护】相关选项时，会按以下优先级处理：

  1. 检查 App 是否通过 registerHostService() 注册了 IHostSettingService
  2. 若已注册，调用对应的接口方法获取 App 决定的结果：
    • onDisplayEventDetectionSchedule —— 决定是否显示【守护时间段】
    • onDisplayEventTriggerTypes —— 决定显示哪些【报警事件】类型开关
  3. 若未注册，SDK 使用默认行为（全部显示）

注意事项

Section titled “注意事项”
  • IHostSettingService 继承自 IHostService，通过 GWIoT.registerHostService() 或 GWIoT.registerHostServices() 注册
  • onDisplayEventDetectionSchedule 返回 false 时，SDK 将隐藏【设置/智能守护/守护时间段】设置项
  • onDisplayEventTriggerTypes 接收的 supportTypes 是 SDK 插件当前支持并可显示的全部事件类型，App 返回的类型只能从该列表中选取（只能减少不能增加），SDK 会按返回的列表顺序展示开关
  • 建议在 SDK 初始化完成后、用户进入设备设置页面前完成服务的注册
  • 如果 App 不需要自定义设置，可以不注册该服务，SDK 将使用默认行为（全部显示）
