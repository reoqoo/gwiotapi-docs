设备绑定与管理

本文介绍 GWIoT SDK 的绑定设备入口、设备管理接口。

前提

Section titled “前提”
  • 已完成 SDK 初始化，initialize 返回成功。
  • App 已完成登录，设备归属于登录账号。

使用内置页面或自建页面

Section titled “使用内置页面或自建页面”

绑定设备有两种入口：扫描设备二维码进入、通过产品列表进入。 SDK 均内置了相关的界面，接口是 IBindComponent, IQRCodeComponent。

您可以直接打开内置页面，也可以通过SDK提供的接口自己定制页面。

除了扫码和产品列表入口，具体的设备/产品绑定流程，涉及比较复杂的和设备、云端交互的协议，均由SDK内置，暂时无法自定义。

内置扫码页

Section titled “内置扫码页”

SDK 内置扫码页面，识别到设备二维码后进入绑定。 页面标题与提示文案可以替换。

自建扫码页与二维码识别

Section titled “自建扫码页与二维码识别”

自行实现扫码，把二维码内容交给 SDK 识别，进入绑定流程。

内置产品列表页

Section titled “内置产品列表页”

SDK 已实现支持的产品列表页面，用户在其中选产品进入绑定。

自建产品列表

Section titled “自建产品列表”

先取支持的产品列表，自行设计实现，按需过滤排序。

用户选中后，把产品信息对象交给 SDK 进入绑定。

后续绑定步骤仍由 SDK 完成。

设备管理接口

Section titled “设备管理接口”

设备管理相关接口是 IDevMangerComponent。 它提供产品列表、设备列表与设备详情三类查询。 每次查询除了返回结果，还会更新对应的缓存 List。

调用 返回 同时更新
queryProductList() 支持的产品列表 产品列表缓存
queryDeviceList() 当前账号的设备列表 设备列表缓存
queryDevice("deviceId") 单台设备详情 该设备的缓存

三端示例

Section titled “三端示例”

Swift

Section titled “Swift”

Swift 示例只覆盖内置页面入口。 用产品或二维码内容进入绑定的方法名，以接口参考为准。

Kotlin

Section titled “Kotlin”

Dart

Section titled “Dart”

内置扫码页识别到的类型，通过 qrCodeRecognized 事件流返回。

验收

Section titled “验收”
  • 绑定完成后，设备列表里出现新设备。
  • 重启 App 后，该设备仍在列表里。
  • 自建产品列表里的产品名称，与 SDK 缓存一致。
  • 扫码识别到设备二维码后，能进入绑定流程。
  • 设备从账号移除后，列表随之刷新。
