Android 集成

本插件依赖私有 Nexus 上的 com.gwell:gwiotapi（KMP SDK 的 AAR）。该产物不在 Maven Central， 因此每个宿主 App 都必须自行声明私有仓库并提供凭据。插件内部的仓库声明不会覆盖宿主 App 的 依赖解析。

3. SDK 与工具链要求

Section titled “3. SDK 与工具链要求”
配置 要求 依据
minSdk >= 24 插件合并后的 manifest 注入 minSdkVersion="24"，宿主更低会导致 manifest 合并失败。
compileSdk >= 36 插件按 36 编译；AAR 不会强制宿主使用 36，但该组合是经过验证的。
Java / Kotlin jvmTarget 11 插件字节码是 Java 11（class 文件 major version 55）。
android.useAndroidX true 插件经 SDK 使用 androidx.lifecycle.Observer；设为 false 可能导致运行期 NoClassDefFoundError。
buildFeatures { dataBinding = true } 宿主 App 的 android/app/build.gradle.kts 必须打开 SDK 内置页面（扫码页等）继承 DataBinding 基类，androidx.databinding.DataBindingUtil 静态初始化时会加载 androidx.databinding.DataBinderMapperImpl；该聚合类只由开启了 dataBinding 的模块生成，宿主不打开时一进扫码页就崩，见第 6 节。
AGP / Kotlin 8.9.1 / 2.1.0 插件构建所用版本，也是当前 Flutter 模板默认值。保持一致最稳妥。

4. 不需要做的事

Section titled “4. 不需要做的事”
  • 不需要额外权限。 android/src/main/AndroidManifest.xml 是空壳，合并结果只带 uses-sdk。
  • 不需要额外 Activity 或 provider。 普通 FlutterActivity 即可；插件会自行跟踪附着 的 Activity 并在初始化时交给 SDK。
  • 不需要自定义 <application> 或 Application 子类。
  • 推送的注册由宿主 App 负责，展示与跳转仍归 SDK。 插件既不申请通知权限也不注册 push token， 只负责把你交给它的 token 传给 SDK。有两层容易漏掉的事实：
    1. 聚合包 com.gwell:gwiotkit 的传递依赖里自带一套 FCM 服务（com.jwkj.lib_gpush 的 FcmPushService），SDK 初始化后会在登录成功时自动注册它。宿主若要自己接 FCM，应在 InitOptions 里传 disablePushNotification = true 关掉内置服务，再自行取 token 调 uploadPushToken。该开关关掉的只是注册与接收，不是 SDK 的推送处理能力。
    2. 无论走内置服务还是宿主自接，收到推送后都要把原始数据交给 receivePushNotification / clickPushNotification。解析、通知展示与点击跳转由 SDK 负责——宿主不要自己再发一条通知， 否则同一条推送会弹两次。

5. Release 构建与混淆

Section titled “5. Release 构建与混淆”

插件不提供 consumer ProGuard/R8 规则。若宿主开启 minifyEnabled 或 shrinkResources， 请自行验证 release 构建——本仓库尚未验证过这一场景。

6. 常见报错排查

Section titled “6. 常见报错排查”
现象 原因
Could not resolve com.gwell:gwiotapi 并返回 401/403 凭据缺失或错误。确认 GWIOT_MAVEN_USERNAME / GWIOT_MAVEN_PASSWORD 对 Gradle 可见。
同上但返回 404 私有仓库未声明，或该版本不在 maven-releases 中。
Uses-sdk … minSdkVersion 24 cannot be smaller than version … declared in library 宿主 minSdk 低于 24。
Unsupported class file major version 或 Kotlin 元数据错误 宿主 jvmTarget 低于 11，或 Kotlin/AGP 版本远低于 2.1.0 / 8.9.1。
进入 SDK 内置页面（扫码页等）时闪退，java.lang.NoClassDefFoundError: Failed resolution of: Landroidx/databinding/DataBinderMapperImpl;（栈顶为 DataBindingUtil.<clinit> → ABaseMVVMDBActivity.onContentViewLoad） 宿主没打开 buildFeatures { dataBinding = true }。SDK 的 AAR 里只有各自包名下的 mapper（如 com.jwkj.lib_base_architecture.DataBinderMapperImpl），聚合类要由宿主模块生成。
Manifest 合并失败并提到插件包名 宿主声明了冲突的 package/namespace。插件使用 com.yoosee.gwiot_flutter_plugin。
