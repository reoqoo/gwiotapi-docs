一、SaaS Webhook 消息文档

Section titled “一、SaaS Webhook 消息文档”
项目 说明
接口地址 POST https://domain/openapi/guestCloud/app/webhook
安全机制 X-IotVideo-Nonce、X-IotVideo-Timestamp、X-IotVideo-Signature 签名验证
处理要求 签名验证、幂等处理、异步处理、错误重试、状态确认
语言版本 中文 / 英文

支持的 Webhook 事件类型

Section titled “支持的 Webhook 事件类型”
事件类型 eventType subType 说明
订单状态变更 ORDER 0/1/2/3 订单创建、支付成功、退款、超时取消
关系链变更 DEVICE 1/3/4/5/6/7/8 绑定、分享（账号邀请/扫码）、解绑、删除访客
绑定事件 Bind 1/2 获取 Token、绑定成功

核心价值：将订单流转、设备归属变更等关键业务事件实时推送给客户系统，实现业务联动和数据同步。

二、设备上线离线信息

Section titled “二、设备上线离线信息”
项目 说明
事件类型 ONLINE_MSG
推送场景 设备上线或离线时触发
核心字段 online（状态：0=离线，1=在线）、devid（设备ID数组）、occurTime（UTC时间戳）
推送方式 消息推送
语言版本 中文 / 英文

核心价值：实时感知设备网络状态，支持批量设备状态同步，便于客户系统进行设备在线监控和状态管理。

三、离线推送协议

Section titled “三、离线推送协议”
项目 说明
推送场景 设备触发告警或产生通知时，向用户 App 推送消息
消息类型 EVENTALARM（设备告警事件）、DEVICENOTICE（设备通知消息）
语言版本 中文 / 英文

核心价值：覆盖从 AI 智能告警到设备状态通知的全场景消息推送，帮助客户构建完善的设备事件响应体系。

消息格式通用规范

Section titled “消息格式通用规范”

所有消息均遵循以下通用结构：

字段 类型 说明
eventId String 请求会话唯一性 ID，用于幂等处理
eventType String 消息类型，如 ONLINE_MSG、ORDER、EVENTALARM 等
subType Number 事件子类型，用于细分同一类型下的不同场景
data Object 具体业务数据，结构随事件类型变化

接入建议

Section titled “接入建议”
  1. 签名验证：Webhook 接入时，务必实现签名验证逻辑，确保消息来源可信。
  2. 幂等处理：基于 eventId 做幂等控制，避免重复处理同一事件。
  3. 异步处理：耗时操作建议异步执行，及时返回响应避免超时。
  4. 错误处理：按照文档要求返回标准响应格式，便于平台进行重试和状态确认。
  5. 多语言对照：中英文文档内容一致，可根据团队语言习惯选择对应版本参考。
