订单状态变更消息（支付成功等）

Section titled “订单状态变更消息（支付成功等）”

字段详细说明

Section titled “字段详细说明”
公共参数：
Section titled “公共参数：”
字段 类型 必填 说明
eventId String 是 请求会话唯一性ID
eventType String 是 事件类型，固定为“ORDER”
subType Number 是 事件子类型：
0: 订单创建
1：支付成功 
2：退款
3: 订单超时取消
data定义：
Section titled “data定义：”
字段 类型 必填 说明
timestamp Number 是 事件发生时间戳（秒）
orderId String 是 订单ID
mainOrderId String 否 多设备订单的主订单ID（不为空代表多设备订单，与orderId一致则当前订单为主订单）
tradeNo String 是 第三方交易号
accessId String 是 用户ID
deviceId String 是 设备ID
simId String 否 ICC ID
packageNo String 是 套餐编号
pkgType String 是 套餐类型 
1：云存
2：4G
orderType Number 是 订单类型：
1：普通购买 
2：续费购买 
3：续费代扣
payWay String 是 支付方式 
3:Paypal
11:Stripe  16:Apple 17:Google
4:兑换码兑换
5:首次订阅赠送
amount Number 是 实付金额（分）
currency String 是 货币代码
limitUnit String 是 服务期限单位
DAY
MONTH
YEAR
limitNum Number 是 服务期限数量

Webhook回调处理

Section titled “Webhook回调处理”

Webhook接收端应该：

验证签名：通过X-IotVideo-Signature确保消息可信

幂等处理：通过eventId避免重复处理

异步处理：对于耗时操作采用异步方式

错误重试：处理失败的消息会进行重试机制

状态确认：返回确认响应
