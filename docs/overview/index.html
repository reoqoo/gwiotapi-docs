概述

GWIoT是技威（Gwell）开发的移动端App智能视频设备方案插件化SDK，配合开发者平台、生产配置能力，OEM合作伙伴可以基于技威成熟方案，快速开发定制摄像头等视频产品和自有品牌的App。

优势

Section titled “优势”
  • 快速接入，支持定制，从易到难渐进式集成
  • 全新开发App，或嵌入客户已有App的账号设备体系，均可
  • Flutter或者原生iOS、Android开发，自由选择
  • 定期同步技威公版App的稳定功能特性和用户体验设计
  • …

技术栈

Section titled “技术栈”

目前SDK提供原生 iOS、Android SDK 与 Flutter 插件。

功能接口基本一致，同步更新。

详见接口分层。

功能边界

Section titled “功能边界”

SDK 内置: App与设备固件侧协议、设备功能的界面与交互、与技威云之间的通信等

App 实现：账号管理/对接、App框架(如设备列表页、账号信息等），及其他自己品牌的业务功能。

详见功能边界。

开发者平台

Section titled “开发者平台”

包括产品管理、应用管理、设备管理、增值管理等功能，目前主要由技威相关接口人进行产品和应用的维护，对客户账号开放设备、订单查询等部分权限。

详见开发者平台

名词解释

Section titled “名词解释”

浏览本站文档时常见的术语名词。

名词 说明
OEM Original Equipment Manufacturer, 原始设备制造商
KMP Kotlin Multiplatform, 由 JetBrains 开发并受 Google 正式支持的开源跨平台技术
Flutter 由 Google 开发的开源跨平台 UI 软件开发工具包，允许开发者使用单一代码库构建同时运行在 iOS、Android、Web、Windows、macOS 和 Linux 六大平台上的原生编译应用
GWIoT 技威提供给OEM客户的设备接入SDK，方便快速开发自有品牌App
客户 App 指集成 SDK 的客户自有品牌 App，本站文档通常直接以App代称
宿主 指客户App或者demo App，相对于SDK，App即其宿主，SDK中需要App实现的接口/协议通常以IHost作为前缀命名。
客户云 客户App对应的自行开发维护的后端
公版App 技威开发的 App（Yoosee、Reoqoo），非自有品牌化的技威方案设备接入

完整术语表在名称解释更新。
